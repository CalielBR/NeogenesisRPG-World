# NEOGENESIS 2326 - RPG Campaign Page

---

## [PT-BR] Português do Brasil

### 🎯 Intenção do Projeto
Este projeto nasceu da necessidade de oferecer uma experiência superior para jogadores de RPG que utilizam dispositivos móveis. O foco principal é fornecer uma plataforma acessível e otimizada para leitura, movendo os registros de campanha para fora dos jornais internos dos VTTs (Virtual Tabletops), como o **Foundry VTT**.

### 📱 Foco Mobile-First
Muitas vezes, acessar os jornais dentro do Foundry VTT através de um celular pode ser uma tarefa árdua devido ao peso do software e às limitações de interface em telas pequenas. Esta página serve como uma "ponte tática", permitindo que os jogadores consultem:
- **Dossiês de Personagem:** Informações detalhadas com visual cyberpunk.
- **Logs de Missão:** Narrativas justificadas e formatadas para leitura suave.
- **Agenda:** Cronograma de sessões de fácil acesso.

### ✨ Diferenciais
- **Layout Flexbox:** Totalmente responsivo para Desktop e Mobile.
- **Leitura Confortável:** Textos alinhados e justificados com tipografia de terminal.
- **Estética Cyberpunk:** Interface imersiva com efeitos CRT e scanlines.

## [EN] English

### 🎯 Project Intent
This project was born out of the need to offer a superior experience for RPG players using mobile devices. The primary focus is to provide an accessible and reading-optimized platform, moving campaign records out of internal VTT (Virtual Tabletop) journals, such as **Foundry VTT**.

### 📱 Mobile-First Focus
Often, accessing journals within Foundry VTT via a mobile phone can be an arduous task due to the software's resource intensity and interface limitations on small screens. This page serves as a "tactical bridge," allowing players to check:
- **Character Dossiers:** Detailed information with a cyberpunk visual style.
- **Mission Logs:** Justified and formatted narratives for smooth reading.
- **Schedule:** Easy-to-access session timeline.

### ✨ Key Features
- **Flexbox Layout:** Fully responsive for both Desktop and Mobile.
- **Comfortable Reading:** Aligned and justified text with terminal typography.
- **Cyberpunk Aesthetics:** Immersive interface with CRT effects and scanlines.
